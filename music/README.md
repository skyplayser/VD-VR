# Hintergrundmusik

VD VR spielt nach der Startanimation „Chill Out“ von **atlasaudio**, von [Pixabay](https://pixabay.com/music/)
(Pixabay-ID 621545, [Pixabay Content License](https://pixabay.com/de/service/license-summary/)).

Die Pixabay-Lizenz erlaubt den Track in einer App, aber nicht, ihn für sich allein weiterzugeben. Deshalb liegt er nur in
der fertigen App (Releases), **nicht** in diesem Repository.

Für einen eigenen Build: auf Pixabay „atlasaudio chill out“ suchen, den Track laden und als `music/atlasaudio-chill-out-621545.mp3` hier ablegen. Ohne
die Datei läuft VD VR ganz normal, nur ohne Musik.
